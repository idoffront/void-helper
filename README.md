# Void-Helper

В будущем буду добавлять все больше утилит для прекрасного пользования Linux'ом.
**Сейчас есть:**
- TUI **(vh)**
- вывод информации **(vh info)**
- поиск пакетов **(vh find)**
- обновление **(vh update)**
- проверка сервисов **(vh check)**

**Поддерживаемые дистрибутивы:**
- Void
- Debian
- Ubuntu
- Mint
- Fedora

Для добавления вашего дистрибутива напишите в issue.


## В планах:
- **desktop preset**: установка нужного граф окружения с удалением старого, добавление новых сервисов в автостарт.
- **Мульти-дистрибутивность+**: Работа на большем количестве дистрибутивах.

## Как скачать??

Ввести одну простую команду:
```bash
curl -fsSL https://raw.githubusercontent.com/idoffront/void-helper/main/install | bash
```
Оно скачает **vh** в временную директорию (на будущее), перекинет в /usr/local/bin и удалит временный репозиторий.

Если вам нужно обновить **vh**, то просто введите:
```bash
vh update-vh
```
