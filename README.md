# Void-Helper

Маленький помощник для самых и не самых пользователей Void Linux.
В будущем скрипт будет улучшаться и дополняться.

**Сейчас есть:**
- TUI **(vh)**
- поиск пакетов **(vh find)**
- обновление **(vh update)**
- проверка сервисов **(vh check)**
- установка пресетов **(vh preset)**

## Как скачать??

Ввести одну простую команду:
```bash
curl -fsSL https://raw.githubusercontent.com/idoffront/void-helper/main/install | bash
```
Оно скачает **vh** в временную директорию, перекинет в /usr/local/bin и удалит временный репозиторий.

Если вам нужно обновить **vh**, то просто введите:
```bash
vh update-vh
```
